Kebijakan Privasi

Berlaku sejak 25 November 2026 · Versi beta

laku.ai adalah layanan klinik bisnis untuk pemilik UMKM. Halaman ini menjelaskan data apa yang kami simpan, untuk apa, dan bagaimana Anda dapat menghapusnya. Kami menulisnya sesuai cara aplikasi bekerja saat ini.

1. Data yang kami simpan

Jenis dataIsiSumber

Aplikasi tidak memakai cookie iklan, pelacak pihak ketiga, atau alat analitik perilaku. Peramban Anda menyimpan token sesi dan cache aplikasi di penyimpanan lokal perangkat agar Anda tetap masuk dan aplikasi bisa dibuka tanpa internet.

2. Untuk apa data dipakai

  • Menjalankan layanan: menghitung skor kesehatan usaha, analitik, rekomendasi stok, dan HPP untuk akun Anda sendiri.
  • Menjaga keamanan akun, misalnya membatasi percobaan masuk yang berulang.
  • Kami tidak menjual data Anda, tidak memakainya untuk iklan, dan tidak membagikannya ke pengguna lain. Data satu akun tidak dapat dibaca oleh akun lain.

3. Di mana data disimpan

Data disimpan di Google Sheets milik pengelola laku.ai dan diakses lewat Google Apps Script. Halaman aplikasi dilayani oleh GitHub Pages. Kedua layanan ini bertindak sebagai penyedia infrastruktur dan tunduk pada kebijakan masing-masing. Selama masa beta, akses langsung ke spreadsheet dibatasi untuk pengelola. Pengelola dapat melihat data di dalamnya untuk keperluan pemeliharaan.

4. Keamanan

  • Kata sandi disimpan sebagai hash dengan garam acak; kami tidak dapat melihat kata sandi Anda.
  • Setiap permintaan data wajib membawa token sesi, dan server hanya mengembalikan data milik akun pemilik token.
  • Namun, tidak ada sistem yang sepenuhnya bebas risiko. Layanan ini masih berstatus beta.

5. Hak Anda: akses, unduh, dan hapus

  • Unduh data: menu Akun → "Unduh data saya" (berkas JSON).
  • Hapus data contoh: menu Akun → "Hapus data contoh".
  • Hapus akun: menu Akun → "Hapus akun dan semua data". Akun, profil usaha, produk, penjualan, promosi, riwayat harga, keputusan, dan sesi dihapus dari spreadsheet. Pengguna Google mengonfirmasi dengan mengetik email.
  • Permintaan lain terkait data Anda dapat disampaikan melalui menu Akun di aplikasi.

6. Penyimpanan

Data disimpan selama akun aktif dan dihapus saat Anda menghapus akun. Sesi kedaluwarsa otomatis setelah 30 hari.

7. Anak-anak

Layanan ditujukan bagi pemilik usaha dewasa dan tidak ditujukan bagi anak di bawah 17 tahun.

8. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal "Berlaku sejak" di atas akan diperbarui. Perubahan yang berdampak besar akan kami umumkan di aplikasi.
